这是一个非常标准且结构清晰的**视频生成模型评测（Evaluation）流程**。

我来帮你整理一份专属的“傻瓜式”指标运行说明文档。根据你 `evaluation` 文件夹的结构，整个流程分为 **“准备数据”、“提取特征/帧”** 和 **“计算指标”** 三步。

---

### 📊 StableAnimator 评测指标运行说明文档

#### 📦 第一步：数据归位（准备弹药）

评测脚本不会自己去找文件，你必须把对应的文件放在它指定的目录里。根据你的 `data` 文件夹结构，请严格对齐：

1. **你的测试输出 (`generated_videos`)**：把你用模型刚刚生成的视频（比如 `2.mp4`，`test_01.mp4`）放进这里。
2. **原始驱动图 (`source_images`)**：也就是生成这些视频时用的那张静态图片（泥塑图或真人图），名字最好和生成的视频对应（比如视频叫 `2.mp4`，图片叫 `2.jpg`）。
3. **真实参考视频 (`gt_videos`)**：Ground Truth（标准答案）。如果是跑你之前的人类动作，就把对应的人类真实视频放进来。

#### 🚀 第二步：一键运行评测

原作者非常贴心地写了一个 **`run_eval.py`** 作为总控开关。通常情况下，你只需要在终端进入 `evaluation` 目录，然后运行这个文件即可。

**基础运行命令：**

```bash
cd /gaojiawei/wjl/StableAnimator/evaluation
python run_eval.py

```

*(💡 提示：如果不确定它需要什么参数，可以先敲一行 `python run_eval.py --help`，它会打印出所有可填的路径和参数说明。)*

#### 🛠️ 第三步：分步运行（如果一键脚本报错）

如果你不想跑所有的指标，或者 `run_eval.py` 报错了，你可以进入 `metrics` 文件夹，**挨个执行单独的指标脚本**：

1. **提取图像帧 (FID 的前置准备)：**
计算图像指标前，需要把视频切成一张张的图。
```bash
python metrics/extract_frames_for_fid.py

```


*(这会在 `data` 里生成 `generated_frames` 和 `gt_frames`)*
2. **计算 CLIP-I (图像一致性)：**  大点好
检查生成的视频和原图“长得像不像”，有没有严重变形。
```bash
python metrics/calculate_clip_i.py

```


3. **计算 FVD (视频时序连贯性)：**
视频生成领域最核心的指标！评价视频的动态自不自然、像不像真实视频。（注意：**FVD 越低越好！**）
```bash
python metrics/calculate_fvd.py

```


4. **计算 SSIM/PSNR (像素级画质还原度)：**
对比生成的视频帧和真实视频帧，看看像素模糊程度。（越高越好）
```bash
python metrics/calculate_ssim.py

```
